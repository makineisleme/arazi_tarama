# Version

Current package version: **0.1.0** (defined in `pyproject.toml`).

The older 0.1.0–0.3.0 entries in `CHANGELOG.md` record prototype development milestones; they are not published package releases. Change the package version in `pyproject.toml` when preparing a formal release.

## Release policy

- Patch: compatible fixes and stability improvements.
- Minor: backward-compatible capabilities.
- Major: incompatible public API or behavior changes.

This repository remains a prototype. A version number does not imply hardware qualification or flight-safety certification.
